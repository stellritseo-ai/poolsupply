## AEO — Answer Engine Optimization

AEO targets Google's **Featured Snippets**, **People Also Ask (PAA)** boxes, and **Direct Answer** panels.

### Strategy
1. **FAQPage schema** on root and blog — direct Q&A markup that Google can pull into PAA
2. **HowTo schema** on homepage — step-by-step instructional query targeting
3. **Concise answer format** — each FAQ answer is 40–80 words, structured to be directly readable by Google
4. **Question format** — all questions mirror actual search query phrasing

### Questions Targeted for Featured Snippets

```
- "What pool equipment brands does Pool Supply Wholesalers carry?"
- "How do I get wholesale pool equipment pricing?"
- "Does Pool Supply Wholesalers ship nationwide?"
- "What is the difference between a variable speed and single speed pool pump?"
- "How do I choose the right variable speed pump for a commercial pool?"
- "What is the difference between a cartridge filter and a sand filter?"
- "How long does a commercial pool pump motor last?"
- "What is the best pool automation system for commercial pools?"
- "How do I size a pool salt chlorinator?"
- "Are Pentair and Hayward prices negotiable for commercial accounts?"
```

## GEO — Generative Engine Optimization

GEO targets **AI-powered search engines** — ChatGPT Search, Perplexity, Google AI Overviews, and Microsoft Copilot — to ensure Pool Supply Wholesalers is cited as an authoritative source.

### Strategy

| Signal | Implementation |
|---|---|
| **Speakable schema** | `SpeakableSpecification` on FAQPage — AI assistants prioritize speakable-marked content for citation |
| **sameAs social profiles** | Facebook, Instagram, LinkedIn, YouTube — establishes entity identity across the web |
| **knowsAbout** | 7 topical areas on Organization schema — signals topical authority to AI knowledge graphs |
| **ItemList schema** | AI models cite structured lists when answering "what are the best X" queries |
| **Blog content depth** | 7 expert long-form articles — AI models prefer citing pages with demonstrable expertise |
| **Entity mentions** | Consistent use of brand names (Pentair, Hayward, Jandy) signals topical relevance |
| **E-E-A-T signals** | Founder names, 25+ years experience, physical address, phone number, parent company |

### GEO Content Principles Applied
- **Factual, citable claims** — specific model numbers, technical specs, statistics
- **Authoritative brand** — Organization schema with verified business details
- **Topical comprehensiveness** — covers pumps, heaters, filters, automation, salt, lights, commercial
- **Named entity density** — Pentair IntelliFloXF, Hayward TriStar VS, Jandy AquaLink RS, etc.
